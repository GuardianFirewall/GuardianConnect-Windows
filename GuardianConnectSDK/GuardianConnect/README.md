This is the GuardianConnect SDK
From this, you can create your own client UI to interact with the GuardianConnect API.

In this API contains the necessary classes, methods and data elements to 
provide authentication, configuration and connection to the Guardian Firewall VPN infrastructure.

Additionally, in the GuardianConnect SDK nuget bundle, there is a GuardianFirewall Service executable
that you will run on the target system which will handle all the actual Windows Operating System calls
for creation, configuration and activation of IKEv2 and WireGuard VPN connections.
